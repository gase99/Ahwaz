Ahwaz Code Studio
@tgcloud v2.1 · Telegram Serverless
👋 خوش آمدید به Code Studio (Telegram Serverless)!
پشتیبانی از مدل‌های رایگان OpenCode Zen، FreeLLMAPI / ApiFreeLLM، LLM7 بدون کلید، OpenRouter :free، Groq و Google Gemini.
    ⚙️ تنظیمات کلید و مدل

    ارائه‌دهنده، کلید API / آدرس سرور و مدل کدنویسی را برای هر سرویس تنظیم کنید. وضعیت فعال بودن نمایش داده می‌شود (کلیدها محافظت شده و هرگز در محیطی نمایش داده نمی‌شوند).

    📘 راهنمای اتصال به کلیدها و مدل‌ها

    روش اتصال، کلید لازم، دستور ربات و لینک ثبت‌نام برای هر سرویس. لینک‌های ثبت‌نام در مرورگر داخل تلگرام باز می‌شوند.

    🤖 دستورات ربات تلگرام
    • /start — داشبورد و وضعیت سرویس‌ها
    • /provider <سرویس> — انتخاب سرویس: opencode, freellmapi, apifreellm, llm7, pollinations, openrouter, groq, gemini, custom
    • /opencode [KEY] — مدل‌های رایگان OpenCode Zen / ثبت کلید رایگان
    • /freellm <URL> [KEY] [MODEL] — اتصال به روتر FreeLLMAPI · /freellm <KEY> — ApiFreeLLM.com
    • /setkey <سرویس> <KEY> — ثبت امن کلید API (پیام حاوی کلید حذف می‌شود)
    • /setcustom <URL> [KEY] [MODEL] — اتصال به هر سرویس سازگار با OpenAI
    • /model <model_id> — تغییر مدل کدنویسی
    • /project <name> · /files · /zip · /clear · /status — مدیریت پروژه
    • /ghclone <repo> · /ghpush <repo> <پیام> — اتصال به GitHub

    ثبت مینی آپ: پس از اجرا کردن npm run deploy، آدرس خروجی (Static: https://app<id>.tgcloud.ai/) را با دستور /setminiapp https://... در ربات ثبت کنید تا دکمه Code Studio فعال شود.
