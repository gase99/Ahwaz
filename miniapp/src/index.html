🧩 مدیریت مدل‌ها و کلیدهای API

هر سرویس یک کارت مستقل دارد: وضعیت اتصال با نشان رنگی، کلید ماسک‌شده و آدرس اندپوینت در بلوک‌های چپ‌به‌راست مونواسپیس، تاخیر پاسخ و دکمه‌های لمسی تست و کپی. کلیدها رمزنگاری‌شده در SQLite ذخیره و با چت تلگرام همگام می‌شوند.

🔌 وضعیت اتصال‌ها

نمای فشرده همه سرویس‌ها؛ نشان وضعیت، مدل فعال، تاخیر پاسخ و دسترسی سریع به تست، تغییر مدل یا قطع اتصال.

    📘 راهنمای دستورات چت و مینی‌اپ

    تمام تنظیمات بین مینی‌اپ و چت تلگرام دوطرفه همگام هستند. راهنمای گام‌به‌گام هر سرویس داخل همان کارت سرویس، در بخش «راهنمای اتصال» قرار دارد.

    🤖 دستورات ربات تلگرام
    • /start — داشبورد اصلی و وضعیت سرویس‌ها
    • /keys — وضعیت کلیدهای ذخیره‌شده با دکمه‌های شیشه‌ای تست و حذف
    • /model — منوی شیشه‌ای گروه‌بندی‌شده انتخاب مدل
    • /model list — گزارش متنی همه سرویس‌ها و مدل‌ها با وضعیت کلید
    • /model <model_id> — تغییر مستقیم مدل کدنویسی
    • /provider <سرویس> — انتخاب سرویس هوش مصنوعی
    • /setkey [سرویس] <KEY> — ثبت امن کلید API (حذف خودکار پیام حاوی کلید)
    • /opencode [KEY] — مدل‌های رایگان OpenCode Zen یا ثبت کلید رایگان
    • /freellm <URL> [KEY] [MODEL] — اتصال به روتر FreeLLMAPI یا ApiFreeLLM
    • /setcustom <URL> [KEY] [MODEL] — اتصال به سرویس سازگار با OpenAI
    • /guide [سرویس] — راهنمای کامل اتصال و مدل‌های رایگان هر سرویس
    • /project <name> · /files · /zip · /clear · /status — مدیریت پروژه
    • /ghclone <repo> · /ghpush <repo> <پیام> — اتصال به GitHub

    ثبت مینی‌اپ: پس از اجرای npm run deploy، آدرس خروجی (Static: https://app<id>.tgcloud.ai/) را با دستور /setminiapp https://... در ربات ثبت کنید تا دکمه Code Studio فعال شود.
